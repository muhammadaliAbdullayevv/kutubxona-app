# Kutubxona — book browsing Mini App

A static, self-contained web app for browsing the book catalogue behind a Telegram bot —
search, filter by genre/audience/format, favourites, and a dedicated Qur'on section.

Generated from the bot's database (source stays in a private repo); this repo holds only
the built static output — no application code.

Live: served via GitHub Pages from this repo's `main` branch, root.
